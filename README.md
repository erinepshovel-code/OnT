# OnT — Thoughts on the Threshold of Project Status

OnT preserves thoughts that have crossed from discussion into plausible project status without pretending they are already ratified, implemented, canonical, or complete.

Current stage: a provisional lexical activation registry plus compact candidate captures. The intended future skill will raise OnT during live threads when historically calibrated EDCM patterns resemble projects that were later pursued to completion.

A raised OnT candidate records provenance, purpose, constraints, placement, promotion conditions, and unresolved `hmmm`. Raising one does not create a repository, authorize implementation, alter canon, or convert generated material into Erin Patrick Spencer's approval.

This repository also retains earlier local working material for Interdependency, AI Council, math visualization, trauma-aware language, and quarantined disturbing material. It remains intentionally minimal and phone-friendly.
