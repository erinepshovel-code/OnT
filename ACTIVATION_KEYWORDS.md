# OnT Activation Keywords

Status: provisional lexical registry

Purpose: provide a conservative trigger surface for raising **OnT — On Threshold** during a live thread until activation can be correlated against historical EDCM traces and projects pursued to completion.

`raise OnT` means: mark a newly forming project candidate for compact capture. It does not by itself create a repository, promote a claim, alter canon, or interrupt work already underway.

## Seed activation table

| Signal class | Activating words or phrases | Strength | Use condition |
|---|---|---:|---|
| Explicit OnT | `OnT`; `on the threshold`; `thought on the threshold`; `thoughts on the threshold`; `threshold of project status`; `raise OnT`; `put this in OnT` | hard | Raise unless the phrase is quoted, historical, or explicitly negated. |
| Preserve for later | `needs a note`; `note somewhere`; `future reference`; `pick up later`; `park this`; `save this`; `return to this`; `come back to this`; `not now`; `defer` | strong | Must refer to a concrete idea, domain, mechanism, artifact, or unanswered project question. |
| Project formation | `this should be a thing`; `make this a skill`; `needs its own repo`; `create a repo`; `build this`; `application`; `module`; `tool`; `workflow`; `vertical slice`; `project status` | strong | Must identify or imply a purpose, artifact, or operating boundary—not merely mention the word. |
| Structural placement | `same treatment`; `just like`; `belongs in`; `use the existing pattern`; `not a standalone note`; `for METAPAT`; `for UCNS`; `for EDCM`; `for skill-lib`; `downstream of` | strong | Requires a named existing project, pattern, application family, or architectural relation. |
| Commitment | `do it to it`; `do this`; `proceed`; `commence`; `deposit`; `approve`; `approved path`; `implement`; `merge`; `push`; `finish`; `continue` | amplifier | Never activates alone. It strengthens an already forming candidate and records willingness to pursue it. |
| Evidence and completion | `what is needful`; `next empirical step`; `ready for real-system`; `first PR`; `release`; `tests`; `evidence`; `evidence locker`; `handoff`; `ship` | amplifier | Requires a project-formation, placement, or preservation signal in the same thread. |
| Boundary and importance | `must`; `load-bearing`; `highest priority`; `immediate task`; `scope boundary`; `preserve`; `exact`; `do not change`; `fail-closed`; `no transfer` | amplifier | Signals seriousness and constraint density, not project status by itself. |
| Recurrent named concept | a distinctive noun or phrase repeated across turns and made more specific after correction | strong pattern | Add the concept to the live candidate vocabulary for that thread. Recurrence without increasing specificity is not enough. |

## Provisional activation rule

Raise OnT when either:

1. one unnegated **hard** signal appears; or
2. two **strong** signals from different classes appear in the same thread; or
3. one **strong** signal appears with two distinct **amplifiers**.

A match should be delayed until a natural response boundary when immediate execution is already in progress.

## Suppression table

| Suppressor | Examples | Effect |
|---|---|---|
| Explicit rejection | `do not save`; `not a project`; `do not pursue`; `discard this`; `never mind` | Do not raise OnT. |
| Idle inquiry | `just curious`; `hypothetically`; a single explanatory question with no placement, preservation, or formation signal | Do not raise OnT. |
| Bare project vocabulary | isolated use of `project`, `repo`, `skill`, `build`, or `application` | Insufficient without context. |
| Existing active work | instructions that only continue an already recognized project | Do not create a duplicate OnT candidate; only raise a newly branching thought. |
| Quotation or analysis | trigger language quoted from another source or discussed as an example | Do not treat quoted language as user commitment. |

## Seed trace: corvid communication

The following sequence is a clear positive example:

- `this should be a thing for metapat/ucns/EDCM`
- `requires a note somewhere`
- `same treatment`
- `future reference to pick up later`
- `OnT`
- `do it to it`

Result: raise an OnT candidate for a future corvid-communication application spanning METAPAT, UCNS, and EDCM.

## Provisional EDCM linkage

The keyword table is a temporary proxy, not an EDCM reading. Future work should compare candidate activations with historical completed-project threads for patterns including:

- increasing constraint resolution and specificity;
- correction incorporation that changes structure rather than wording;
- persistent recurrence without non-integrative looping;
- movement from exploratory language to bounded placement and action;
- low overhead relative to concrete project formation.

Only correlations that distinguish completed projects from abandoned or merely discussed ideas should survive into an executable OnT skill.
